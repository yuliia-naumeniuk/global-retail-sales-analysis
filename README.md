# Global Retail Sales Analysis
Python data analysis project exploring global retail sales data to understand product performance, geographic trends, and delivery efficiency.

## Business Task
Analyze company sales data to identify key trends in product categories, geographic performance, and shipping efficiency.

## Tools
Python (Pandas, NumPy), Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization (Matplotlib, Seaborn)

## Key Insights
- Sales vary significantly across product categories.
- Some countries generate much higher revenue than others.
- Sales trends change over time.
- Certain regions dominate overall sales performance.
